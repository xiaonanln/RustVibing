# RustVibing 🦀

Learn Rust by Vibing - A beginner-friendly Rust learning project!

## About

This project is designed for learning Rust with AI assistance. The code demonstrates fundamental Rust concepts with clear examples and comments.

## Getting Started

### Prerequisites

- Install Rust: https://www.rust-lang.org/tools/install
- Or use `curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh`

### Running the Project

```bash
# Build the project
cargo build

# Run the project
cargo run

# Run tests (when available)
cargo test
```

## What You'll Learn

This project covers:
- ✅ Variables and Mutability
- ✅ Functions and Parameters
- ✅ Control Flow (if/else, loops)
- ✅ Basic Ownership and Borrowing
- 🔜 Structs and Enums
- 🔜 Error Handling
- 🔜 Common Collections
- 🔜 And more!
